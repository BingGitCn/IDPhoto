# IDPhoto · 光影小馆 证件照生成器

一个**纯静态**的证件照制作网页：上传一张自拍，AI 在浏览器里自动完成抠图换底、人脸对齐、标准裁剪，可选轻度美颜，下载即用。

**照片全程在本地处理，不上传任何服务器。**

## 功能

- 🖼 上传 / 拖拽 / Ctrl+V 粘贴自拍
- 🤖 本地 AI：MediaPipe 人像分割（抠图）+ 人脸检测（自动构图对齐），边缘精修（去镶边 + 羽化）
- 🎨 底色：白 / 蓝 / 红 / 深蓝 / 浅灰 + 自定义色
- 📐 规格：一寸、二寸、小二寸、身份证、签证（均按 300 DPI 输出标准 px 尺寸）
- ✨ 美颜：保细节磨皮 + 提亮（关闭 / 轻度 / 中度），仅作用于人物区域
- 🖨 六寸相纸冲印排版一键导出（JPG / PNG）
- 🛰 拍摄质量提示：光线偏暗、人脸过小、白底配浅色衣物等

## 使用

直接访问 GitHub Pages，或本地起任意静态服务器：

```bash
python -m http.server 8765
# 打开 http://localhost:8765/
```

> 仓库已包含 `mediapipe/` 模型文件（约 26MB），HTTP 访问时模型本地加载、断网可用；
> 只部署单个 `index.html` 时会自动回退到 CDN 加载。

## 技术栈

纯 HTML / CSS / JS 单文件页面 + Canvas 合成，无任何构建过程与后端。
AI 推理使用 MediaPipe（Selfie Segmentation + Face Detection，WASM/WebGL）。

## 隐私

所有处理均在浏览器本地完成，照片不会离开你的设备（详见页面内说明）。
